# Визуальный аудит VNE Portal

Аудит фиксирует 19 пользовательских HTML-маршрутов при ширинах 360, 390, 430, 1440 и 1920 px: всего 95 кадров. Машинные endpoints (`/mcp`, `/sitemap.xml`, `/.well-known/*`) не имеют визуального интерфейса и в матрицу не входят.

## Запуск

```bash
bun run test:visual
```

Команда создаёт актуальные кадры в `docs/sprint/visual-regression/current/`, сравнивает их с `baseline/`, сохраняет видимые различия в `diff/` и пишет `report.json`. Ошибка возвращается при HTTP 4xx/5xx, ошибке страницы, незагруженной картинке, горизонтальном выходе или визуальном расхождении выше допуска.

## Намеренное обновление

После ручной проверки осознанного изменения интерфейса:

```bash
bun run test:visual:update
bun run test:visual
```

Обычный запуск никогда не изменяет baseline. Сравнение игнорирует разницу каналов до 16 и допускает не более 0,1% изменившихся пикселей. Тест использует `prefers-reduced-motion`, DPR 1, русскую locale и отключённые CSS-анимации, чтобы кадры были воспроизводимыми.
