## Причина и изменение

В Sites отсутствует конфигурация клиентского Supabase. `MotionProvider` при
монтировании безусловно обращался к ленивому клиенту для чтения `motion_defaults`.
Клиент пытался прочитать серверный `process.env` в браузере; синхронное исключение
попадало в корневую границу ошибок, заменяя сайт экраном «Страница не загрузилась».
Сервер при этом отдавал HTTP 200, поэтому прежние проверки только SSR не выявляли сбой.

Теперь необязательное чтение общих настроек выполняется только при наличии
клиентской конфигурации. Ошибки инициализации/сети оставляют встроенные настройки.
Недоступное хранилище браузера также не останавливает страницу. Поздний ответ
не перезаписывает новый личный выбор и не обновляет размонтированный провайдер.
Правила доступа, существующий вход администратора, медиа и базы не изменены.
