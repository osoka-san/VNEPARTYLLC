# Кабинет, навбар и цвет собственного ответа

Дата: 2026-10-06. База: опубликованная версия 18, commit `09d6bda750c2cb72a44316a623f91a774ce673f6`.

## Изменения

- Отдельная группа `navbar` в общих настройках: 8 числовых параметров, 3 фирменных акцента, подпись приглашения, показ верхних ссылок и глав главной. Рабочее встроенное меню в панели управления. Сохранение только владельцем, проверка версии, сброс, актуализация и импорт/экспорт; схема настроек 9 совместима с прежними данными.
- Кнопки собственного ответа в Bloom и вверху анкеты: голубой `#86ABFF`, тёмный текст `#070A09`, наведение `#E55330`.
- `/member` в текущем Sites-режиме: список собственных заявок из формы, фильтры, страницы по 20, карточка с исходными ответами, история, обновление каждые 30 секунд в активной вкладке и вручную, ответ на уточнение.
- Администратор задаёт отдельный вопрос для гостя. Только явно выделенный вопрос виден в кабинете; старые и новые внутренние заметки остаются в админке. Ответ гостя возвращает заявку на рассмотрение, сохраняется в истории и журнале; повтор запроса не дублирует запись.
- Профиль: сохранение имени, смена пароля с проверкой текущего и повтором нового, ограничение попыток, завершение других сеансов при смене пароля, выход. Смена имени сохраняет действующие сеансы.
- После отправки анкеты добавлен переход в кабинет. Сохранены все обязательные вопросы и лимит до трёх ответов.

## Границы

Кабинет обслуживает существующие тестовые учётные записи Sites. При подключённом основном backend этот API отключён; существующие проверки допуска и staff/MFA не заменяются тестовым входом. Административные записи заявок не привязываются к гостю по совпадению email. Новая регистрация, реальные платежи, Telegram и выпуск пропуска не подключены этой правкой. Новые схемы БД и внешние уведомления не добавлены.
