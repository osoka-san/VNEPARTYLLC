# V06 — единый стеклянный экран загрузки

Дата: 2026-10-06. База: f04c09ce420eb26d767db4c7eb8ba7012cac99ac.

Запрос: установить Wormhole из https://uiverse.io/elijahgummer/polite-earwig-72
в состояниях загрузки, по центру поверх слегка приглушённого размытого сайта,
в фирменном мятно-циановом цвете.

## Реализация

- Десять колец исходного CSS-референса; локальные CSS/JS без внешних запросов.
  MIT-атрибуция сохранена в public/licenses/uiverse-wormhole.txt.
- Один экран на корень приложения, вне анимируемых контейнеров страниц.
  Стекло: затемнение 27%, blur 10px (8px на телефоне), приглушение насыщенности.
- Начальная SSR-разметка, переходы маршрутизатора, активные запросы без данных,
  первый hero/портал и eager-изображения, формы входа и заявки, админские
  сохранения/загрузка данных, библиотека/рендер/проверка QR, открытие пропуска,
  сканер и применение общих настроек подключены к общему счётчику.
- Нативный POST на странице входа сохранён. Скрипт не читает поля формы.
  Показывает тот же загрузчик при отправке и сбрасывает его при pageshow.
- Короткие операции до 180 мс обходятся без мигания. Видимый цикл длится
  минимум 320 мс; окончание одного параллельного запроса не закрывает остальные.
  Завершение, ошибка и размонтирование освобождают свою регистрацию.
- Через 10 секунд можно продолжить просмотр. Это только убирает стекло,
  не подтверждает успех операции и не снимает блокировки формы.
- No-JS скрывает начальную пелену. При сбое JS bootstrap она исчезает через
  12 секунд. У native login есть аналогичный таймаут возврата формы.
- Системный и ручной reduced-motion дают статичное светящееся кольцо.
  Фоновое обновление кэша и изображения ниже первого экрана не блокируют чтение.
- Готовность hero и уход LQIP по-прежнему требуют decoded image + portal-ready.
  Ошибка картинки отдельно завершает ожидание, сохраняя существующий LQIP.

## Настройки загрузчика в админке — 2026-10-06

Путь: `/admin?section=motion#loading-settings`.

Добавлена группа «Загрузка сайта» с 26 параметрами:

| Группа  | Параметры                                                                                   |
| ------- | ------------------------------------------------------------------------------------------- |
| Режим   | Туннель, пульсация, орбита, статичный, выключен; прямое/обратное направление                |
| Форма   | Скорость, количество колец, диаметр, масштаб на телефоне, размах, смещение, толщина контура |
| Свет    | Основной/второй цвет, цвет блика, яркость, сила свечения, непрозрачность                    |
| Стекло  | Цвет, затемнение, размытие для компьютера и телефона, насыщенность фона                     |
| Подписи | ВНЕ, текст текущего состояния                                                               |
| Время   | Задержка, минимальная длительность, переход, порог предложения продолжить просмотр          |

Есть пресеты «Неон ВНЕ», «Мягкий свет», «Спокойный»; живое превью с переключением
компьютер/телефон, повтор и ограниченная тремя секундами демонстрация на весь экран.
Размеры свечения малого индикатора пропорционально уменьшены.

Настройки входят в MotionSettings v8 как вложенная группа loading и в восьмую
группу общих настроек. Сохраняются отдельно или вместе с остальными. Запись
по-прежнему доступна только owner, reviewer может обновить сохранённую версию.
Старые настройки получают неоновый вариант по умолчанию; частичный импорт
не сбрасывает остальные параметры загрузчика. Режим «Без движения» включает
статичное кольцо, системное reduced-motion имеет приоритет.

Обёртка Worker добавляет только очищенные публичные параметры оформления в
первый HTML, включая вход и публичный пропуск. Это даёт сохранённый вариант
до гидратации и не открывает доступ к API настроек, ролям или данным аккаунтов.
Ошибка необязательного чтения оформления не ломает страницу.

Повторно проверено: TypeScript, preview-defaults (68 полей, 8 групп),
site-loading (настраиваемые таймеры и нативный вход), production build и
SSR всех 30 маршрутов. Дополнительно проверены отдельное сохранение loading,
запрет записи reviewer, наследование на первом HTML, безопасные границы
чисел/цветов и сохранение страницы при сбое хранилища оформления.
