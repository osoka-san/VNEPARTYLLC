# Инструкция: аккаунт (DRAFT 0.1)

## Целевой путь (PLANNED, AUTH-02/03)
1. Вход через Telegram.
2. Возврат на сайт: email как логин, пароль и его повтор.
3. Подтверждение email.
4. Один аккаунт для Telegram и email+пароля.

## Что есть в коде сейчас (AUTH-01)
Аккаунт создаётся по приглашению после одобрения заявки; Telegram входит только в уже привязанный аккаунт; в сбросе пароля нет повтора. Инструкцию гостю по целевому пути не публиковать до реализации (K02).

## Операции
Привязка/отвязка Telegram, восстановление, выход — есть. Удаление аккаунта — [УТОЧНИТЬ] (AUTH-04). Совпадение email, потеря Telegram — [УТОЧНИТЬ] (AUTH-06). Чужие аккаунты автоматически не объединяются.
