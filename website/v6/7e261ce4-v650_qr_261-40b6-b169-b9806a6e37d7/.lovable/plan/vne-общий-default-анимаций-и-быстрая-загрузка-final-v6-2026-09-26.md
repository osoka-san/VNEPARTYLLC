# VNE: общий default анимаций и быстрая загрузка final-v6

## Результат

Второй загруженный JSON станет новым встроенным набором анимаций по умолчанию. Внизу панели движения появится кнопка «Сделать default»: она безопасно сохранит текущие настройки админки как общий default для всех посетителей без личных настроек. Изображения final-v6 будут быстрее и чётко появляться на mobile и desktop.

## Что изменю

1. **Новый встроенный default**
   - Перенесу все значения из `schemaVersion_revealStyle_ease_pasted-2.json`, включая mask-заголовки, параметры spring, повторы и выбранные Scramble targets.
   - Text Scramble останется только на явно зарегистрированных местах; статусы, CTA и ошибки автоматически затронуты не будут.
   - Существующие личные настройки в браузере останутся приоритетнее общего default.

2. **Общий default из админки**
   - Добавлю одну защищённую запись настроек в Lovable Cloud с версией схемы, временем изменения и автором.
   - Чтение общего default будет публичным и безопасным: только валидированная модель движения, без пользовательских данных.
   - Сохранение разрешу только сотруднику с правом редактирования контента, живой сессией и подтверждённым вторым фактором; проверка будет выполнена на сервере.
   - Внизу панели движения добавлю кнопку «Сделать default» с подтверждением, состояниями сохранения/ошибки и сообщением об успехе.
   - После сохранения текущий набор станет стартовым для новых посетителей и для «Сбросить»; уже сохранённые личные настройки не будут перезаписаны.
   - Если сеть недоступна или общий default повреждён, сайт без пустого состояния использует встроенный второй JSON.

3. **Ассеты final-v6**
   - Оставлю установленный комплект из 88 AVIF/WebP: SHA-256 уже подтвердил полное побайтовое совпадение с архивом.
   - Сохраню отдельные mobile/desktop композиции, все валидные ширины без апскейла и резервную скульптуру вне событий.

4. **Быстрая и чёткая загрузка**
   - Добавлю раннюю адаптивную загрузку главного изображения с правильной mobile/desktop композицией и высоким приоритетом.
   - Приоритетно загружу первое значимое изображение страниц событий и «О проекте»; остальные останутся отложенными.
   - Фоны следующих глав начнут подготавливаться ближе к экрану, не загружая всю библиотеку сразу; режим экономии трафика сохранится.
   - Сохраню AVIF/WebP и выбор подходящей ширины по экрану и плотности пикселей — без снижения качества исходного кодирования.

5. **Проверка**
   - Проверю встроенный и облачный defaults, личный override, сброс, отказ без права/MFA, повреждённые данные и сетевой fallback.
   - Проверю главную, события и «О проекте» на mobile/desktop: выбранный URL, фактическую ширину, декодирование и отсутствие пустых кадров.
   - Выполню целевые тесты, проверки типов, стиля и сборки; публикацию не запускаю.

## Технические детали

- Новая таблица получит явные GRANT, RLS и единственную серверную операцию записи с существующей capability `content`; роли остаются только в `staff_assignments`.
- Общий default загружается один раз и проходит существующую строгую санитизацию schema v6 до применения.
- Без изменений утверждённых изображений, текстов, композиций, Gallery Continuation, WebGL, Auth, ролей и оплаты.
