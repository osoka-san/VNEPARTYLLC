# ВНЕ / Gallery of Light / final-v6

Единый комплект из **14 изображений**: 7 окончательно выбранных пользователем кадров из `vnev57asstS.zip` и 7 новых композиций для оставшихся ролей сайта. Это не новый набор из 28 альтернатив. Выбранные 7 PNG сохранены побайтово; контрольные SHA256 указаны в манифесте.

## Что внутри

- `index.html` — локальная галерея всех 14 изображений. Распакуйте архив целиком и откройте файл в браузере.
- `masters/` — 14 неизменённых PNG-оригиналов.
- `public/media/gallery-of-light/final-v6/` — 88 адаптивных файлов: 44 WebP и 44 AVIF.
- `asset-manifest.json` — роли, статусы, размеры, объём каждого файла, URL и SHA256.
- `INTEGRATION_RU.md` — точное соответствие разделов и имён ассетов.
- `optimization-report.json` — фактические объёмы и настройки экспорта.
- `generation-prompts.json` — финальные промпты 7 новых композиций и имена референсов.
- `export-input.json`, `optimize_assets.py` — переносимые исходные данные и скрипт воспроизводимого экспорта.

## Выбор пользователя сохранён

Порог: C desktop + C mobile. Свои: D mobile. Приглашение: C mobile. Интервал света: C. Камень: D. Скульптура: C.

Новые изображения: Пространство desktop/mobile, Свои desktop, Приглашение desktop, Сосны, Вода, обложка «Ритм в камне». Все относятся к единой виртуальной локации: графитовый каменный дом, сосновый двор, широкие проёмы, приглушённый тёплый свет и холодные вечерние полутона. Изображения сгенерированы, а не сняты на реальном объекте; точная CAD-модель здания не создавалась.

Резервная скульптура остаётся резервом. Пакет содержит 13 основных ролей и один запасной кадр, не третье событие. Кадры 02/04, формы и юридические страницы не требуют дополнительных фоновых изображений. Логотип, шрифты, SVG и WebGL-портал не являются заменяемыми фотоассетами.

## Переходы и прокрутка

Композиции связывают вход, лесную террасу, гостиную и обратный взгляд во двор. Это основа для перехода 06 → 01. Кадры не являются пиксельно бесшовными тайлами: переходы выполняются слоями на сайте. Текст и управление остаются отдельными доступными HTML-элементами.

Сами ассеты и эта локальная галерея не подтверждают внедрение бесконечной прокрутки на сайте. Статус реализации и браузерной проверки должен читаться в отдельном отчёте по интеграции. В нативном архиве нет оснований утверждать, что все существующие маршруты уже обновлены.

## Проверка при подключении

Проверить desktop 1440/1920 и mobile 360/390/430 px с настоящим текстом. Мобильные 05/06 сохраняют выбранную пользователем композицию; окончательное кадрирование и локальное CSS-затемнение под длинными строками определяются на странице. Для 03 mobile проверить текст в нижней половине относительно светлых деревьев/пола. Не затемнять PNG деструктивно.

Для повторного экспорта нужен Python с Pillow и AVIF-кодеком. Команда из распакованной папки: `python optimize_assets.py`. Доступен параметр `--workers 3`. Повторный экспорт может иметь отличающиеся байты при другой версии кодеков; качество, размеры и входные PNG фиксированы.
