## Результат

- Единое верхнее меню на всех страницах админки. 11 разделов, активный пункт, URL для локальных вкладок, перенос строк на узком экране, резерв высоты. Панель вне анимированного контейнера.
- Переписанное детерминированное ядро `vne-glyphs-0.2.0`. Из матрицы Q строится граф тёмных модулей; безопасные диагонали, покрытие открытыми цепочками, S-повороты, без тесных возвратных петель. Выбор из 8 стандартных масок. «Поток» предпочитает диагонали и получает срезы; «Синкопа» предпочитает ортогонали и мягкие окончания.
- Служебные центры сохранены; защитное поле 4 модуля со всех сторон. В каждом модуле защищено центральное поле 0.24×0.24. Наружная часть модулей может изгибаться; акценты окрашивают до трёх коротких неслужебных глифов. Это новая геометрическая модель, прежняя гарантия центральных 0.56×0.56 к ней не применяется.
- Генерация редактора и серии выполняется в отдельном Web Worker. Изменение ввода отменяет устаревший расчёт; интерфейс не блокируется длинными строками. Холодный расчёт 220 байт занимал около 5.5 сек в локальном Bun, поэтому вынос из UI необходим. В памяти ядра — ограниченный кэш 8 раскладок; хранения/отправки payload нет.
- Вкладка «Сравнение»: предоставленные референсы 02/04, прежний генератор и новые реальные QR с текстом «на удачу». Исходные изображения включены без изменения пикселей, область референса показана через CSS.
- Библиотека в D1: поиск по названию/метке мероприятия, неизменяемые версии, история последних 50, архив/возврат, копия, открытие старой версии с созданием новой при сохранении.
- Один предыдущий несохранённый вариант можно вернуть после открытия другого/пресета/импорта. Ошибка сохранения не сбрасывает редактор. Повтор запроса сохраняет operationId; конфликт не перезаписывает чужую версию.
- JSON-файл сохраняет версию движка. Неизвестный движок отклоняется; legacy JSON открывается с явным сообщением об изменении рисунка.
- Проверка jsQR перед экспортом привязана к полным SVG и тексту, размеры 900/420/280. SVG и PNG доступны только после проверки текущего результата.

## Сохранение и доступ

Новая D1 таблица `qr_pattern_versions` хранит только рецепты дизайна, метку мероприятия и версии. Payload QR, пропуска, гости и платежи не принимаются этим API. Миграция schema-only, без seed; существующая предметная база не копируется.

`/api/qr-studio/patterns` повторно проверяет подписанную сессию существующего парольного шлюза, Origin для POST, sec-fetch-site, фактический лимит тела 12 КБ, UUID, строгие поля/enum/диапазоны. Ответы private/no-store. Атомарный INSERT создаёт ревизию только при актуальном expectedVersion; уникальный operationId делает повтор идемпотентным.

Временный парольный доступ допустим только при полностью неподключённом backend. Любой сигнал Supabase/auth в env или process.env закрывает API до интеграции с штатным staff/MFA guard. Реальная авторизация не обходится. Аудитория, credentials, issuer, `/pass#token` и допуск не менялись.

Runtime не вызывает AI API; расходы AI-токенов на генерацию отсутствуют. Хостинг/хранилище — существующий Sites.

## Проверки и визуальная оценка

- 40 SVG, 20 payload × 2 стиля: детерминизм, строгие входы, защищённые центры и полное quiet zone PASS.
- ZXing-C++: 200/200 точных байтов: 900/420/280 px, JPEG q75 420, blur 0.45 420.
- jsQR: 120/120 точных текстов и UTF-8 байтов на 900/420/280.
- OpenCV: 188/200. Все 100 тестов «Потока» прошли. 12 отказов «Синкопы»: десять при 280 px и два при 420 px. Для ночной палитры OpenCV получает явную инверсию. Между декодерами есть разница; нельзя обещать чтение любой камерой.
- Реальная локальная SQLite + фактический API handler: 60 проверок PASS, включая 2 сессии, конкурентные изменения, повтор запроса, архив/историю, Unicode поиск, пагинацию, auth/Origin/валидацию и fail-closed.
- TypeScript и production build PASS. Контракт собранного Web Worker (успех/ошибка) PASS в отдельном Node thread; browser E2E это не заменяет.
- 6 регрессионных тестов шлюза PASS. Worker SSR 19 маршрутов: 11 видимых ссылок и ровно один активный пункт на каждой проверенной admin странице; сеть запрещена, backend не подключён.
- Независимое read-only ревью: исправлены потеря предыдущего оформления и отсутствие версии движка в файле.
- Независимая экспертная визуальная оценка этих двух PNG: «Синкопа» 70/100, «Поток» 69/100. Рубрика: крупные S/C-глифы 30, вес/плавность 20, окончания 15, интервалы 15, маркеры 10, палитра 10. Баллы: 19/14/11/9/9/8 и 19/14/11/9/8/8. Это субъективный художественный балл, не измеренный процент совпадения и не гарантия для каждого payload. Требование пользователя ≥65% **не выдаётся за объективно доказанное**. Художественное утверждение владельца остаётся открытым.
- Остаточные визуальные отличия: тонкие швы между соседними формами, длинные вертикали, более простые оранжевые вставки. При длинных payload QR плотнее референса.

Доказательства: `evidence/stage2/`. Браузерное взаимодействие, мобильный адаптив и физическая камера **NOT VERIFIED**: требуемый Sites managed preview навык control-browser недоступен. SSR/Node raster checks не подменяют browser E2E.
