# Каталог референсов и предпросмотр карточки

Запрос: добавить все шаблоны с пяти присланных листов в админку и кнопку перехода к билету, на котором виден выбранный QR. Работа разрешена существующим запросом; публикация в том же Sites-проекте с прежней аудиторией.

База: Sites v9, `f4544c9bf4e01c2b934c43d3f8be072779328390`. Проект `appgprj_6aba5314956c8191b34f93f81538f7bf`.

## Проверяемый результат

- Все 16 референсов доступны отдельными плитками; есть фильтр коллекций и переключение референс/рабочий QR.
- Для каждого шаблона доступны настройка и переход «На карточке».
- В разделе билетов открывается QR-сторона демонстрационного пропуска; доступны лицевая сторона, тип допуска, имя и мероприятие.
- Студия → карточка → студия сохраняет полный паттерн и исходный текст без помещения содержимого QR в URL.
- Художественные адаптации программные, без AI API и токенов. Исходные изображения обозначены как референсы.
- Проверка чтения выполняется до использования художественного QR; при отказе показывается обычный код с тем же payload и явным статусом.
- Предпросмотр не выпускает билет, не меняет допуски и не обращается к issuer.

## Границы

Фотографическая точность и процент сходства не заявлены. Генератор должен хранить реальные данные, поэтому композиция меняется с текстом. Публикация интерфейса не включает развёртывание Supabase Edge Function. Существующий недоступный сервер выпуска остаётся отдельным незавершённым этапом. Физическая камера и браузерный E2E не проверены в этой итерации.
