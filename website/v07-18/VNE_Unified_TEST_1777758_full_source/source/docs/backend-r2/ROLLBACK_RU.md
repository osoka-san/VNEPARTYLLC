# Остановка и восстановление

Ни один пакет сейчас не применён в живой среде. Эти заметки описывают план,
а не разрешение на изменение прав или удаление данных.

## Ошибка во время применения

Каждый SQL-файл заключён в одну транзакцию. При ошибке проверки базы, индекса,
владельца функций или DDL транзакция должна откатиться целиком. Не продолжать
выполнение по отдельным фрагментам и не отключать проверки, чтобы обойти ошибку.
Сначала проверить фактическую схему и историю миграций; повторять только если
установлено, что первый запуск не зафиксирован. `CREATE` намеренно не заменяет
уже существующие функции незаметно, поэтому слепой повтор не предусмотрен.

## Пакет структуры применён, доступ ещё не открыт

Оставить новые столбцы, индексы и закрытые функции на месте. Сайт по-прежнему
не может использовать новые операции. Удаление структуры не требуется для
немедленной безопасной остановки. Проверить отсутствие случайных грантов.

## Доступ к двум операциям уже открыт

Если нужна остановка, после отдельного разрешения отозвать только EXECUTE роли
authenticated на двух публичных функциях:

- public.vne_submit_membership_questionnaire(jsonb)
- public.vne_read_my_membership_questionnaires(uuid)

В одной транзакции убедиться, что PUBLIC/anon/service_role также не получили
EXECUTE, и проверить фактические права после фиксации. Отозванные права не
прерывают уже выполняющийся запрос: учесть завершение текущих транзакций.
Не выдавать новых прав приватным функциям/таблицам для «временного исправления».
Если флаг сайта ранее включался с отдельного разрешения, его выключение также
должно входить в явно согласованную операцию; текущий пакет флаг не включает.

## Полный возврат структуры

Не удалять новые столбцы, заявки или ответы автоматически. Если появились
записи, удаление может быть необратимой потерей данных и требует отдельного
плана сохранения/сроков хранения и соответствующего разрешения.

Прежний уникальный индекс по pending email нельзя восстановить вслепую:
новая модель намеренно допускает одинаковый контактный email разных владельцев.
Перед возвратом нужен анализ только разрешённых данных и решение о конфликтах;
нельзя объединять, присваивать или удалять заявки по совпадению email.

## После остановки

Проверить: нет доступных новых публичных операций у запрещённых ролей; таблицы
и private-схема не открыты; при отказе сервер не сообщает об успешном сохранении;
заявки/снимки не повреждены. Не считать отзыв прав доказательством успешного
восстановления всей пользовательской цепочки без отдельной проверки.
