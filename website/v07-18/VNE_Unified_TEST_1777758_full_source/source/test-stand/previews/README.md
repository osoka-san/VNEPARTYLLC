# Synthetic mobile previews

These self-contained review artifacts are hosted by the existing TEST Site at
`/preview`, `/preview/menu`, `/preview/pass`, and `/preview/violations`.
The catalogue also links the existing authenticated TEST routes. No live owner
pass, scanner, incident or review backend is enabled by these artifacts.

The build reads exactly these three HTML files through
`scripts/test-preview-pages.mjs`; the output guard serves only four exact paths.
Each demo is placed inside `srcdoc` with an opaque-origin sandbox. Scripts and
synthetic React form events are allowed; same-origin access, storage, popups,
top-level navigation and camera are not. A restrictive CSP blocks every network
connection and native form submission. No real account data, tickets or secrets
belong in these files.

When replacing or adding a requested TEST prototype, deliver its HTTPS route
and update the catalogue in the same TEST release. An HTML download alone is
not the mobile delivery path. Preserve the current authenticated route guards,
server-function allowlist, six-account allowlist, runtime flags and audience.
Preview hosting never authorizes production deployment, SQL/RPC activation,
role grants or changes to authentication.
