# Расширение Text Scramble во VNE Portal

## Результат

Text Scramble станет отдельной управляемой системой для заранее зарегистрированных редакционных акцентов. Эффект останется opt-in: кнопки, статусы, формы, даты, цены, навигация, юридические страницы и служебные зоны не будут затронуты.

## Реализация

1. **Явный реестр мест**
   - Добавить типизированный реестр со стабильными ID, маршрутом, секцией, русским названием, группой, типом места и значением по умолчанию.
   - Зарегистрировать подходящие акценты главной, `/about`, `/events`, карточек и страниц событий; безопасные акценты `/faq`, `/contact`, `/rules` подключать только при наличии редакционного назначения.
   - Добавить отдельную opt-in настройку для выбранных коротких `h2`.
   - Подключать эффект только через явный `targetId`; неизвестные ID игнорировать.

2. **Надёжный reusable TextScramble**
   - Вынести чистую логику выбора букв/направления/интенсивности для тестирования.
   - Поддержать длительность, частоту, задержку, интенсивность, направление, набор знаков, повтор при повторном появлении и независимый принудительный replay.
   - Сохранять цифры, пробелы, пунктуацию, slash, регистр, `Ё/ё` и `Й/й`; auto-набор выбирать по исходной букве, mixed/symbols — только из безопасных пресетов.
   - Первый SSR/hydration-кадр и доступное имя всегда показывают исходный текст. Визуальный слой будет `aria-hidden`, без `aria-live`.
   - При reduced/manual/off, отключении общей анимации, группы или места немедленно завершать эффект и очищать observer/RAF/timer.
   - Убрать `whitespace-pre`, сохранить естественные переносы и стабильную геометрию на узких экранах.

3. **Схема настроек v6**
   - Расширить существующие поля Scramble без дублирования master-переключателя: группы, места, короткие заголовки, delay, intensity, direction, charset, repeat.
   - Добавить строгую санитизацию диапазонов и enum, фильтрацию неизвестных групп/ID, защиту от `null`, массивов и нечисловых значений.
   - Мигрировать legacy/v3–v5, сохраняя все несвязанные текущие значения.
   - Обновить presets и карту preview для каждого нового ключа.

4. **Админка и живая проба**
   - Заменить текущий короткий блок Text Scramble единым расширенным блоком: master, понятные ручки, группы, список мест по страницам, «включить/выключить все подходящие», отдельный toggle коротких `h2` и «Сбросить только Scramble».
   - Оставить подписи панели статичными; эффект показывать только в пробе.
   - Добавить редактируемую тестовую строку с RU/EN/Ё/Й/цифрами, видимый off/disabled-статус и кнопку «Повторить», которая всегда запускает новый цикл.
   - Сохранить sticky/mobile preview, presets, общий reset, JSON import/export и browser-local сохранение.

5. **Подключение страниц без двойных reveal**
   - Главная: декоративная hero eyebrow, метка Манифеста и подходящие главы; не трогать H1, `TextRoll «Меньше шума.»`, `TextLoop`, CTA и даты.
   - `/about`: PageShell eyebrow, секции пространства/сообщества и короткие подписи изображений; выбранные короткие `h2` только через отдельную опцию.
   - `/events`: PageShell eyebrow, kicker карточек и редакционные метки detail; статусы, даты, факты и действия остаются статичными.
   - Для узлов Scramble убрать вложенный скрывающий `AnimatedText`/`InView`, если он скрывал бы эффект.

6. **Проверка и документация**
   - Unit: sanitize/clamp, v3–v5 migration, JSON roundtrip, неизвестные ID, protected exclusions, направление/intensity/reveal/replay.
   - Запустить целевые typecheck, lint и build.
   - В Chromium проверить 360/390/430/1440: минимум три реальные точки, промежуточные и финальные кадры, длинный RU/EN, Ё/Й/пунктуацию, overflow/CLS, три replay, все off/reduced/group/target режимы, reload/JSON и кликабельность защищённых элементов.
   - Не обновлять общий visual baseline. Сохранить точечные evidence, обновить `docs/design/site-motion-map.md`, создать `docs/sprint/text-scramble-expansion-report.md` с исходным/итоговым SHA и честными PASS/FAIL/NOT VERIFIED.

## Ограничения

- Только UI/motion текущего проекта; без БД, Auth, Telegram, публикации, смены framework, ветки или истории.
- Оригинальные Flow SVG, портал, палитра, шрифты и существующие TextRoll/TextLoop остаются без изменений.
- Физические устройства, реальный screen reader и связанная GitHub-ветка отмечаются `NOT VERIFIED`, если среда их не подтверждает.
