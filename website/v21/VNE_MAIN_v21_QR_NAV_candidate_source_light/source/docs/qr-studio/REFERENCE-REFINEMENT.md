# Шесть QR-стилей и палитры пропусков

База: опубликованная v20, commit `3a7b6023e925d1fd67ffbff62087c608f205856b`. Эта копия подготовлена для объединённого релиза. Она не опубликована отдельно.

## Согласованная коллекция

Владелец утвердил Оригами, Базальт, Порталы, Созвездие, Плетение и Складки, затем все 24 сочетания с GENERAL, VIP, SECURITY и ARTIST. Для новых макетов интерфейс предлагает только эти шесть стилей. Каталог, поиск, редактор, сравнение и новые билетные варианты используют одну коллекцию.

Полный реестр 16 стилей, исходные изображения, прежние64 миниатюры и движок `vne-glyphs-0.5.0` сохранены для совместимости. Архивный макет можно просмотреть и экспортировать с записанным движком. Новое оформление создаётся явным выбором или обновлением отдельной копией; исходный QR не заменяется автоматически.

## Версии и палитры

Новые движки имеют идентификаторы `vne-origami-1.0.0`, `vne-basalt-1.0.0`, `vne-portals-1.0.0`, `vne-constellation-1.0.0`, `vne-weave-1.0.0` и `vne-folds-1.0.0`. Их рецепт включает геометрию и палитры. После релиза изменение любого из них требует новой версии с сохранением выпущенного движка.

Прежний `PASS_QR_PALETTES` не изменён. Новый путь использует более глубокие фоны VIP `#0b0f0c` и SECURITY `#07170e`; основные цвета и акценты типов сохраняются. Базальт и Порталы в билетном режиме получают оттенки материала из палитры типа, без примеси канонического мятного цвета в VIP. Канонические оформления не перекрашиваются.

Движок передаётся через библиотеку, sessionStorage-черновик, редактор, Worker, просмотр карточки и снимок дизайна в существующем контракте выдачи. Старый черновик без версии трактуется как0.5. JSON-экспорт сохраняет выбранный движок; SVG/PNG сохраняют текущий вид и выбранную палитру. Тип карточки по-прежнему не предоставляет прав на сайте.

## Геометрические ограничения

Содержимое не меняется: используется исходный UTF-8, коррекция Q, защищённые области модулей и полное свободное поле в4 модуля. Матрица одинакова во всех цветовых вариантах одного стиля и текста.

Базальт: обычный внутренний штрих расширен до1.5625 модуля, то есть ещё на25% от предыдущих1.25. Для матриц больше41 модуля действует предел1.4375 (+15%): более широкие варианты не прошли420px/blur на максимальной строке. Рамки и служебные области не расширяются.

Складки имеют самостоятельную композицию плавных лент, не геометрию Оригами. Целевая ширина0.96→1.152 (+20%); длинные ленты со свободным местом получают1.344 (+40%). У границ и защищённых областей расширение ограничивается; в сохранённой зоне0.25 модуля вокруг reserved используется исходный вариант. Для демонстрации52 элемента имеют цель+20%, пять длинных лент+40%; у33 элементов часть расширения ограничена. Все63 finder-кропа канонического корпуса совпадают с предыдущими на900px. Универсальное равенство пограничных пикселей при любом ресэмплинге не заявляется.

Процент сходства с художественными референсами не измерялся. Исходные изображения не были декодированы в проведённых проверках; это не доказывает невозможность их чтения любым сканером. Готовые формы согласованы владельцем визуально.

## Проверки

На каждый стиль:6 синтетических строк,3 канонические и4 билетные палитры, а также3 варианта без акцентов —45 fixtures. Проверяются900/420/280px, JPEG75 и blur0.45 при420px; для матриц до41 модуля также160/144px. Итого301 вариант на стиль.

- jsQR:1806/1806, точный текст и байты UTF-8.
- Независимый ZXing-C++ с обычным LocalAverage:1806/1806.
- Все24 QR из статических компоновок карточек читаются при204px обоими движками.
- Все64 адресуемые миниатюры полного совместимого реестра декодируются; интерфейс показывает24 новых варианта.30 новых ресурсов добавлены под версионными URL:6 канонических SVG и24 WEBP.
- Прежний движок:224 точных сравнения полного результата на16 стилях. Десять архивных стилей:140 точных сравнений default-ветки. Все64 прежних билетных WEBP неизменны.
- Канонические SVG пяти ранее утверждённых стилей:105 точных совпадений. У Складок18/21 совпадают после исключения внешних aria/role; три максимальные матрицы отличаются только избыточными коллинеарными вершинами и дают попиксельно идентичные900/420/280px изображения.
- Версии/черновики/импорт:22 маршрута рецептов; Worker:19 сценариев; библиотека:116 проверок в изолированном SQLite; issuer:46 локальных тестов с подменённым RPC; остальные unit-тесты:53.

Основные тесты выполняются на изолированной синтетике. Реальные билеты не выпускались и не погашались, общая база и права не изменялись. Проверки браузерного взаимодействия, CSS-кропов реального сайта, физической камеры и печати не выполнены. Изображения для согласования являются явно подписанными статическими компоновками с настоящими QR, не скриншотами сайта.
