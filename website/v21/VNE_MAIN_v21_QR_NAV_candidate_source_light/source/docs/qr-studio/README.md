## Каталог

В `/admin/qr-studio` открывается вкладка «Макеты · 16». Все пять пользовательских листов представлены отдельными плитками: 6 графических и 10 фактурных. Переключатель «Референсы / Рабочие QR» отделяет исходные изображения от программных адаптаций. Рабочие миниатюры содержат текст «на удачу»; индивидуальный рисунок зависит от данных.

| --------------- | --------- |
| Сцепление       | Рёбра     |
| Синкопа         | Складки   |
| Диалог          | Эмаль     |
| Встречный поток | Рельеф    |
| Внутренний круг | Базальт   |
| Тихий сдвиг     | Порталы   |
|                 | Плетение  |

|                 | Созвездие |
|                 | Мрамор    |

Каждая плитка имеет кнопки «Настроить» и «На карточке». Выбор поддержан генератором, JSON-импортом/экспортом и серверной библиотекой. Необязательное поле `template` валидируется по списку из 16 идентификаторов; паттерны прежних версий можно открыть как обновлённую копию.

Графические шаблоны используют сохранённую библиотеку цельных глифов с приоритетами под характер композиции. Фактурные шаблоны строят контуры из настоящей QR-матрицы и применяют процедурный материал внутри маски. Quiet zone — 4 модуля, коррекция Q; служебные области сохраняются. Генерация работает локально в Worker без AI API и токенов.

## Карточка

Маршрут `/admin/tickets?view=preview&template=<id>` открывает демонстрационный билет сразу QR-стороной. Можно переключить макет, тип карточки, стороны, имя и мероприятие. Рядом расположен исходный референс и явный статус проверки QR. При отказе проверки выводится обычный код с тем же содержимым и соответствующее сообщение.

Переход из редактора или библиотеки переносит полный паттерн и исходный текст в ограниченный черновик sessionStorage; URL содержит только идентификатор. Обратная кнопка возвращает эти настройки в редактор. Черновики ограничены 16 записями и действуют в текущей вкладке. Несуществующий или повреждённый черновик вызывает понятную ошибку. Сам просмотр не вызывает выпуск, отзыв или сканирование билетов и не берёт токены настоящих пропусков.

Корпус: 80 изображений — все 16 шаблонов на коротком тексте, синтетическом билетном токене, пределе 220 байт UTF-8 и двух дополнительных палитрах. Полные отчёты лежат в `evidence/stage5`.

ZXing: **400/400** (900/420/280 px, JPEG75 и blur0.45). jsQR: **240/240** (900/420/280 px), точное совпадение текста и байтов UTF-8. Центральное поле модулей и quiet zone: **80/80**. Перед итоговым прогоном уменьшен перепад яркости фактур и исправлено смешение цветов в плетении; проверки чтения не ослаблялись.

Контракт перехода студия/карточка, наличие всех 32 изображений каталога, полное сохранение паттерна и текста, предел локальных черновиков, проверка входных параметров и совместимость импорта: PASS. Серверная библиотека: 93 проверки PASS. Локальный issuer: 40 проверок PASS. Реальный bundled Worker: 3 сценария PASS.

Независимый обзор кода не обнаружил блокеров перехода каталог → карточка → редактор. SSR-smoke включает 21 маршрут, каталог всех 16 макетов и билет, открытый QR-стороной. Проверки браузером и физической камерой не выполнялись.

## Границы

Рабочие SVG являются адаптациями, не фотографическими копиями исходных композиций. Процент сходства не измерялся. Графические различия зависят от допустимых комбинаций настоящего QR и могут быть умеренными. Некоторые фактуры заметнее в крупном SVG, чем на маленькой карточке.

В этой итерации обновлён контракт локального issuer для `template`, но Supabase Edge Function не развёрнута. Прежний блокер серверного выпуска билетов остаётся; предпросмотр независим от него. Переназначаемые редиректы и выдача настоящих билетов не входят в этот этап.
