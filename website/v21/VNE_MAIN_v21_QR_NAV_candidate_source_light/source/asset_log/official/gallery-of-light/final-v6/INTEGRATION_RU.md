# VNE final-v6 — подключение ассетов

Этот архив содержит 7 выбранных пользователем оригиналов v5 и 7 новых композиций v6. Вместе это 14 изображений: 13 для существующих ролей сайта и одна резервная скульптура. Резерв не создаёт третье событие.

1. Скопировать содержимое `public/media/gallery-of-light/final-v6/` в одноимённый каталог проекта.
2. В реестре изображений использовать `base: "/media/gallery-of-light/final-v6"`, точный `stem`, размеры и `widths` из `asset-manifest.json`.
3. Адрес каждого изображения: `${base}/${stem}-${width}.${format}`. В имени файла после ширины **нет** буквы `w`; она нужна только в дескрипторе HTML `srcset`.
4. Для всех 8 полноэкранных вариантов глав сохранить отдельные desktop/mobile композиции. Порог переключения в текущем компоненте — 640 px; не подменять мобильную композицию обрезкой горизонтального кадра.
5. В `GalleryBackground.tsx` убрать старые `replacementMedia`/прямые JPG-импорты, которые обходят реестр, особенно старый водный зал раздела 05. Иначе новые файлы в реестре могут не появиться.
6. Подписи, текст, кнопки, SVG и WebGL-портал остаются отдельными слоями. Никаких букв в изображения не добавлено. Финальные `object-position`, затемнение и контраст проверяются на реальной странице с её текстом.
7. Для фоновых переходов держать текущую и следующую сцены; не загружать все 14 оригиналов/вариантов при первом открытии. PNG из `masters/` не предназначены для сетевой загрузки на сайте.
8. Проверить декодирование AVIF/WebP и сетевые URL после подключения. Ширины/высоты в манифесте — фактические, апскейла нет.

## Область действия

Этот файл описывает медиапакет. Наличие архива само по себе не подтверждает установку на сайт или проверку бесконечной прокрутки. Реализация и результаты её проверки фиксируются отдельно. Старый выбранный 05-C не является горизонтальной парой текущего выбранного 05-D mobile; новая композиция v6 создана для согласования этой пары.
