# VNE: комплект веб-шрифтов

Проверено 23 сентября 2026 года. Все три подключённых файла содержат 66 русских букв: А–Я, а–я, Ёё.

## Подключение

1. Скопировать папку `fonts` целиком в `public/fonts` проекта Lovable.
2. Подключить `/fonts/fonts.css` один раз через `<link rel="stylesheet" href="/fonts/fonts.css">` в корневом документе приложения.
3. Основному тексту и интерфейсу назначить `font-family: var(--font-body)`.
4. Заголовкам назначить `font-family: var(--font-display)`.
5. `HealthGoth` подключать точечно классом `vne-font-accent`, только для короткого декоративного слова. Не применять к кнопкам, меню, форме, дате, пропуску или длинным абзацам.

Декларация `@font-face` сама по себе не требует загрузки всех трёх файлов: браузер загружает шрифт, когда он применяется. Не добавляйте preload для декоративного акцента без измерений. Все ссылки в CSS относительные: файл CSS и WOFF2 должны оставаться в одной папке.

## Состав

| Файл | Назначение | Начертания |
|---|---|---|
| `Unbounded-Variable.woff2` | Основные заголовки | normal, вес 200–900 |
| `Onest-Variable.woff2` | Основной текст и интерфейс | normal, вес 100–900 |
| `HealthGoth-Regular.woff2` | Необязательный декоративный акцент | normal, вес 400 |

Unbounded взят из пользовательского `Unbounded.zip`; одинаковый variable-файл также присутствует в `Manrope,Unbounded.zip`. Onest загружен из официального репозитория Google Fonts: <https://github.com/google/fonts/tree/main/ofl/onest>. Обе variable-гарнитуры упакованы в WOFF2 без сокращения набора глифов; таблица Unicode и порядок глифов проверены после конверсии. HealthGoth WOFF2 скопирован из пользовательского архива без изменений.

Исходные лицензии SIL OFL 1.1 сохранены в папке `licenses`. Не удаляйте их при переносе файлов.

## Исключённые вложения

- **Manrope** пригоден технически и содержит полную русскую кириллицу, но не подключён: пользователь выбрал Onest для основного текста и интерфейса.
- **Metal** — Metal от PizzaTypefaces / Type Tomorrow, а не одноимённый Khmer-шрифт. Во вложении только Trial-файлы; `Befonts-License.txt` явно указывает `Personal Use Only`. В этих файлах отсутствуют Й, й, Ё, ё. Он не включён в комплект для публикации.
- **Nostra Test Sett / Nostra Test Stream** содержат полную русскую кириллицу. Это тестовые файлы Plain Form; подтверждения лицензии на рабочий коммерческий сайт во вложениях нет. Они не конвертировались и не включены в CSS. Встроенная ссылка на условия: <https://plain-form.com/licensing>.

Полная техническая проверка исходных файлов сохранена отдельно в `vne_font_audit.json`.
