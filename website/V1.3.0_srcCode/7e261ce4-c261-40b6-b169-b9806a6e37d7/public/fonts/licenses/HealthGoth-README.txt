# healthgoth

Health Goth is a radical gothic typeface inspired by the old-school blackletter tradition.
The font was created for the Hungry book. Now it's available for everybody.
 
Health Goth это радикальный готический шрифт, вдохновленный позднем традиционным вариантом готического письма, фрактурой.
