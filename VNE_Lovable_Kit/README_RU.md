# ВНЕ — комплект для Lovable

Версия 2, 23 сентября 2026 года. Подготовлены промпт и реальные файлы бренда. Изменения сайта в Lovable этим комплектом ещё не выполнены.

## Что внутри

- PROMPT.md — полный обновлённый стартовый промпт; копировать целиком в Lovable.
- KNOWLEDGE.md — короткие постоянные правила бренда для Project knowledge.
- public/brand/wordmark — выбранное слово «ВНЕ» (Flow) в настоящем SVG.
- public/brand/portal — эталонная эмблема, три отдельных звена и профили для 3D.
- public/fonts — Unbounded, Onest, HealthGoth в WOFF2, готовый CSS и лицензии.
- docs — визуальная проверка шрифтов и техническая информация о файлах.

## Как передать материалы

1. Распаковать архив. Открыть существующий проект: https://lovable.dev/projects/2c267e95-fc84-4cc0-a92e-35270441b83a.
2. В настройках проекта проверить, какой GitHub-репозиторий и какая ветка действительно синхронизированы. Не выбирать ветку по старому сообщению или по догадке.
3. Добавить содержимое папки public из этого комплекта в папку public проекта, сохраняя уже существующие файлы. В итоге рядом с кодом проекта должны появиться public/brand/portal, public/brand/wordmark и public/fonts. Не нужно загружать весь ZIP как один файл в public. Сохранить изменение обычным commit в связанную ветку и дождаться синхронизации Lovable.
4. Открыть PROMPT.md, скопировать весь текст и вставить в чат существующего проекта. Для предварительной проверки выбрать Plan рядом с полем сообщения. Проверить, что план первого этапа включает точные SVG, три выбранных шрифта, выход из дока и сборку арки от прокрутки.
5. После согласования запустить Build первого этапа. Следующие этапы выполнять по готовым командам ниже.
6. Содержимое KNOWLEDGE.md сохранить в Project knowledge как постоянные правила; если там уже есть инструкции, объединить их, а не слепо заменить. Бриф версии 2 должен заменить противоречащие ему старые указания о Manrope, временных кольцах и автоматической сборке.

Если репозиторий ещё не подключён, Plan может разобрать промпт и SVG-референсы уже сейчас. Но файлы шрифтов и точные контуры должны быть реально добавлены в проект перед утверждением результата. Одно упоминание имени файла в чате не передаёт его содержимое.

По текущей документации Lovable отдельной загрузки шрифтов в интерфейсе нет: свои файлы добавляются в репозиторий через Git sync, затем Lovable получает указание использовать их. Google Fonts можно подключить по имени, но в этом комплекте все три семейства уже подготовлены для локальной раздачи из проекта.

## Короткие команды для этапов

### Первый Build

Реализуй первый этап по PROMPT.md: используй точный Flow SVG, три исходных звена 10C11-6 и локальные Unbounded + Onest + HealthGoth. Собери законченный тёмный hero, выход трёх звеньев из дока за примерно 2 секунды только до раздельной позы и точную сборку исходной арки от дальнейшего scroll. Сделай мобильную композицию и статичный fallback. Проверь реальные шрифты, открытые проёмы, ранний scroll, кнопки, build и lint. Пока не включай весь бесконечный цикл и не публикуй.

### Конечная история

Сохрани утверждённый первый экран. Добавь остальные пять глав из PROMPT.md с обычной конечной прокруткой и одной постоянной сценой. Главные заголовки Unbounded, текст и интерфейс Onest, HealthGoth только в редких крупных фразах. Не меняй Flow и портал. Сделай demo-заявку с честным состоянием отправки и доступом с клавиатуры.

### Бесшовный цикл

Замкни готовую историю. p=0 и p=1 должны совпадать в раздельной hero-позе после intro, включая камеру, звенья, свет, фон, док и надпись. Intro не повторяется. Последняя глава мягко возвращает сцену в эту позу. Проверь 10 кругов в обе стороны и отсутствие роста числа ресурсов. Для reduced motion и неустойчивого mobile-loop сохрани конечный вариант.

### Настройка и проверка

Добавь development-only панель из PROMPT.md: камера, глубина, расстояние звеньев, свет, материалы, тайминги, scroll-дистанция, типографика, качество; экспорт JSON и возврат пресета. Проверь 1440×900, 1920×1080, 390×844, ширину 360 px, WebGL fallback, ранний scroll и клавиатуру. Сообщи измеренные результаты и оставшиеся ограничения. Не публикуй автоматически.

## Существенные детали

- Исходная эмблема сохранена; первые три файла пользовательского архива были тремя фонами одной формы.
- Большая голубая, средняя мятная и малая оранжевая арки остаются разными по размеру. Их не нужно уравнивать.
- portal-master.svg — эталон. Все три звена имеют общий viewBox. В финальной 2D-позе их transform — identity.
- SVG уже содержит нарисованную глубину. Для 3D использовать frontProfilePath из manifest. Это реконструкция, не готовая 3D-модель; камера и толщина требуют визуальной настройки.
- wordmark-flow.svg рассчитан на inline SVG/currentColor. Для img на тёмном фоне использовать wordmark-flow-light.svg.
- Все три выбранных шрифта содержат А–Я, а–я, Ёё и Йй. HealthGoth узкий: применять крупно и редко.
- Metal в пользовательском архиве — Trial, Personal Use Only; в нём нет ЙйЁё. NostraTest — тестовые файлы. В рабочий набор они не включены. Визуальное направление можно пересмотреть при наличии подходящих webfont-файлов.
