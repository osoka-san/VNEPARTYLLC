# ВНЕ — постоянные правила проекта

Бренд называется ВНЕ; VNE — латинская запись, без расшифровки. Закрытые вечеринки, приватность, музыка и пространство. Интерфейс на русском. Сохранять существующий TanStack Start + React + TypeScript, Three.js / React Three Fiber / Drei и правила AGENTS.md. Не переписывать опубликованную git-историю.

Утверждённые материалы:
- Flow wordmark — `/brand/wordmark/wordmark-flow-light.svg` или inline `/brand/wordmark/wordmark-flow.svg`. Это векторные контуры «ВНЕ», не обычный текст, не латинский VNE и не PNG.
- Портал 10C11-6 — `/brand/portal/portal-master.svg`. Ровно три вложенные арки: внешняя голубая #86ABFF; средняя мятная #30E5AD; малая внутренняя оранжевая #E55330.
- Группы: portal-link-01 / portal-link-02 / portal-link-03. Исходные пропорции, наклоны, скругления, проёмы и цвета сохраняются. Финальные offsets и frontProfilePath — в portal-manifest.json.
- Первые три SVG исходного архива — три фона одной эмблемы. Версии with-wordmark содержат старую подпись, не использовать её.

Типографика: Unbounded 500–600 — заголовки; Onest 400–600 — текст, меню, формы и CTA; HealthGoth Regular 400 — редкий крупный акцент. Flow SVG доминирует в hero; не конкурировать с ним второй крупной декоративной гарнитурой. Локальные WOFF2 и fonts.css в public/fonts, кириллица проверена. Токены --font-display / --font-body / --font-accent. Manrope заменён на Onest. Metal Trial и NostraTest из вложений не включать в публичную сборку; будущая смена акцентного шрифта возможна после предоставления пригодных webfont-файлов.

Палитра: #070A09 фон, #101715 поверхности, #EDF2EE текст, #30E5AD основной интерфейс, #E55330 CTA, #86ABFF внешняя арка. Тёмный просторный editorial-дизайн, сатинированные материалы, мягкие фаски, сдержанный свет. Сцена ночного леса/архитектуры — художественный фон, не документальные фото мероприятия.

Хореография: intro около 2 секунд только выводит детали из нижнего дока в раздельную позу. Без scroll они остаются раздельными. Дальнейший scroll собирает точную исходную арку; обратный scroll её разбирает. Передняя кромка дока реально перекрывает поднимающиеся детали. Один владелец transforms. Ранний scroll отменяет intro и плавно передаёт управление. Глубокие ссылки пропускают intro.

Исходный SVG — 2.5D-рисунок. Для настоящей экструзии использовать frontProfilePath, а не градиентные rect/clipPath и не все слои исходника. Профили — задокументированная реконструкция; глубину/камеру проверять по master. Не придумывать новый знак вместо согласованного.

Главы: Порог / Манифест / Пространство / Ближайшая ночь / Принадлежность / Приглашение. Сначала конечная история, затем optional infinite loop. Начало и конец loop — одна и та же раздельная hero-поза после intro. Intro в цикле не повторяется. Один Canvas, постоянное число объектов, формы и CTA не дублируются.

Основной CTA «Получить приглашение» доступен всегда. HTML-текст, клавиатура, focus, Escape, корректное управление фокусом. Reduced motion и отсутствие WebGL — статичный собранный портал и обычная конечная страница. На mobile допустим конечный режим при неустойчивом цикле.

Все настройки вынести в design/motion/content config; панель изменения параметров только development. Реальные сведения не выдумывать. Новые заявки и кабинет demo до отдельной интеграции; публичный инвайт, постоянная карта и одноразовый событийный допуск — разные сущности. Существующие подключения сохранять. Визуальный этап не меняет базу/авторизацию/оплату и не запускает публикацию.

Полный storyboard и критерии приёмки — в PROMPT.md. После реализации сообщать фактически проверенные результаты, а не обещания.
